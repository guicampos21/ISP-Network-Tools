# Contributing

This project follows a GPLv3 copyleft model with Linux-style attribution practices.

## Requirements

- Preserve copyright notices in source files.
- Preserve SPDX license identifiers in source files.
- Keep `LICENSE` and `AUTHORS` in redistributions.
- Reflect functional and operational changes in `README.md`, `README.pt-BR.md`, and the relevant files in `docs/`.

## Signed-off-by / DCO

Every contribution must include a `Signed-off-by` line in the commit message:

```text
Signed-off-by: Your Name <you@example.com>
```

By adding this line, you certify that you have the right to submit the contribution under the project license terms.

## Example

```bash
git commit -s -m "Adjust report layout"
```
