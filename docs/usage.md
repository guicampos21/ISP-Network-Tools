# Usage

## Runtime Requirement

Use CPython `3.14`.

## Module Execution

```bash
PYTHONPATH=src python3 -m inh --help
PYTHONPATH=src python3 -m inh example.com
PYTHONPATH=src python3 -m inh 203.0.113.25
PYTHONPATH=src python3 -m inh 203.0.113.0/28 --workers 48
PYTHONPATH=src python3 -m inh AS15169 --approach aggressive
```

## Launcher Execution

```bash
./scripts/inh --help
./scripts/inh AS15169
```

## Main Options

- `--workers`: sets the maximum number of parallel queries.
- `--boost`: enables turbo mode.
- `--approach conservative|aggressive`: chooses between curated sources or the full source set.
- `--report-type 1|2`: kept for compatibility; the final version always generates the complete HTML report.

## Outputs

- terminal progress and final summary;
- complete HTML report;
- JSON summary with execution metadata;
- auxiliary artifacts generated by the application flow.

## Notes

- `NETWORK_SCOPE_BLACKLISTS` raise block/ASN risk, not every individual IP.
- `ASN-DROP` raises the final report risk to `Very high`.
- Informational sources provide context and do not classify an IP as listed on their own.
- In interactive mode, the tool detects the system language and asks whether to keep or switch between `pt-BR` and `en-US`.
- The final HTML report is generated in the same language selected in the application.
- The report includes basic operational metadata such as local username, operating system, language, and execution duration.
