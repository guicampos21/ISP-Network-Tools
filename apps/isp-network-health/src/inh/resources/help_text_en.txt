ISP Network Health

Usage:
  ./inh [TARGET] [--workers N] [--boost] [--approach conservative|aggressive] [--report-type 2] [--help]

Supported inputs:
  domain                  Example: example.com
  single IPv4             Example: 203.0.113.25
  IPv4 CIDR block         Example: 203.0.113.0/28
  ASN in ASxxxx format    Example: AS15169

Behavior:
  - When given a domain, the tool queries the domain itself and the resolved IPv4 addresses.
  - When given a single IPv4, the tool queries the DNSBLs for that address.
  - When given an IPv4 CIDR block, the tool expands the block and checks every IP.
  - When given an ASN, the tool queries:
      * Spamhaus ASN-DROP reputation
      * IPv4 prefixes announced by the ASN
      * summarized BGP connectivity for the upstream view
      * DNSBLs for IPs inside the announced prefixes

Options:
  --workers N
      Sets the maximum number of parallel queries.
      If omitted or set to 0, the tool chooses an automatic value.

  --boost
      Enables turbo mode.
      It aggressively increases parallelism and the internal query queue,
      prioritizing speed in exchange for higher CPU, RAM, and network usage.
      If omitted, the tool may ask interactively whether boost should be used.

  --approach conservative|aggressive
      Selects the query approach.
      Conservative: uses only the most critical and reliable sources.
      Aggressive: uses every source available in the tool.

  --report-type 1|2
      Kept for compatibility.
      This version always generates the complete HTML report.

  --help
      Shows the full help text.

Outputs:
  - Interactive terminal UI with progress, upstreams, and recent events.
  - Complete report artifacts generated by the application flow.
  - Optional full log at the end of execution.

Operational notes:
  - The tool works only with IPv4 and IPv4 CIDR.
  - Very large ASNs may be blocked by operational limits to avoid excessive scanning.
  - Actual speed depends on DNS, network conditions, and blacklist responsiveness.

Examples:
  ./inh example.com
  ./inh 203.0.113.25
  ./inh 203.0.113.0/28 --workers 48
  ./inh AS15169 --workers 64
  ./inh AS15169 --boost
  ./inh 203.0.113.0/24 --boost --workers 96
  ./inh 203.0.113.0/24 --approach aggressive
